Morph

Copy once. Paste right, anywhere.

Morph sits as a slim tab on the edge of your screen and re-shapes what you copied for Slack, Jira, Confluence, Docs, Email, Markdown and more, so tables, lists and code survive the paste. Everything happens on your computer.

Install on Linux

One command, a tiny download, and it uses what GNOME already has: no Node.js, no Electron. Made for Ubuntu and other GNOME desktops on Wayland. No log out needed.

You need

Ubuntu, Fedora Workstation or another GNOME desktop, plus curl and unzip. GNOME's gjs is already part of it.

What it adds

A slim tab on your screen edge, a small GNOME helper and a morph command. No icon in the top bar.

What it reads

Your copies and the front window's app name, only on your computer. Password managers are never read. Nothing is sent anywhere.

1

Run the installer

Paste this into a terminal. It downloads one zip, checks it against its fingerprint, and installs into your home folder. You can read the installer first.

curl -fsSL https://mohitanand001.github.io/morph/install.sh | bash
2

Say hello

A short welcome opens by itself. It says what Morph does and lists the tools it converts for. There's nothing to set up: press Got it, or Open Settings if you'd like Morph to work in only some apps.

You should see a slim tab on the right edge of the screen. Check any time with morph --status.
3

Prefer a package?

A .deb for Debian and Ubuntu installs the same thing system-wide. Install it with sudo apt install ./morph_0.15.0-rc.3_all.deb, then open Morph from the app menu. Updates come from a newer .deb.

Use it

Morph never takes focus, so the paste lands where you were.

1

Copy as usual

From a spreadsheet, Slack, a web page, an AI chat, a terminal or a PDF.

2

Pick where it's going

Click the tab on the screen edge (or press Ctrl Alt F) and choose the app you're pasting into.

3

Paste

Press Ctrl V. Not right? Press Undo in Morph to put your original back. Or skip a click entirely: Ctrl Alt V pastes fixed for the app you're in.

Tables

Spreadsheet ranges, Slack text tables, psql output and web tables become real tables in Jira, Confluence, email and Docs.

Lists

Odd bullets, a) b) numbering and Outlook's fake lists become proper nested lists.

Code and terminal output

Indentation and line breaks survive, and code lands as a code block.

Already fine?

If a paste would already work, Morph leaves it alone and says so.

Privacy

A clipboard tool sees a lot, so here is exactly what Morph does. The code is open, so you can check it.

Stays on your computer

Morph never stores what you copy and never sends it anywhere. Conversion happens locally.

You choose where it works

All apps by default, or only the apps you pick in Settings → Apps. Password managers and copies marked secret are always skipped.

A log you can see

Settings → Privacy lists what Morph read: the time, the app and the size, never the content.

Network

Only an optional daily update check and the optional table OCR download.

Tables from images (optional)

Morph can read a table from a copied screenshot, on your computer, and only when you click an app. It's off by default because it downloads about 1 GB (PaddleOCR). Turn it on in Settings → Privacy → Enable table OCR, or run:

morph --enable-ocr

Update

Morph checks this page once a day (you can turn that off in Settings → Updates). To check yourself, open Morph, then Settings, then Updates. When there's a newer version, Update now installs it and restarts Morph, with no log out. Or from a terminal:

morph --update

Uninstall

Open Morph, then Settings, then Uninstall, or run the command below. It removes everything: the program, the GNOME helper, start-at-login, the command, your settings, logs, caches and the optional OCR files. Installed from the .deb? Run sudo apt remove --purge morph.

morph --uninstall

Troubleshooting

The welcome or the tab doesn't appear

Run morph --status. If the app is running but nothing shows, switch the GNOME helper off and on: gnome-extensions disable morph-focus@morph.dev; gnome-extensions enable morph-focus@morph.dev.

To see the welcome again, run morph --setup.

Morph says "Not read"

You set Morph to work in only some apps, and you copied from another one. Pick an app in Morph to convert it anyway, or switch on All apps in Settings → Apps.

I hid Morph with the ✕

Press Ctrl Alt F, or run morph --restart.

"gjs is missing"

It's part of GNOME, so this is rare. On Ubuntu run sudo apt install gjs, on Fedora sudo dnf install gjs.

Where does it log?

In ~/.cache/morph.log. It never contains what you copied. For more detail, run morph --stop, then FB_DEBUG=1 gjs -m ~/.local/share/morph/daemon/gjs-main.js in a terminal.

Report a problem

Open an issue on GitHub with the two apps involved, what you copied and what you got, plus the output of morph --status. For security problems, use the security policy instead.
