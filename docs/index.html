Copy from anywhere.
Paste it right.

Morph re-shapes what you copy for the app you paste into. Tables stay tables, lists stay lists and code keeps its indentation, across Slack, Jira, Confluence, email, Google Docs and more. For GNOME on Linux.

curl -fsSL https://mohitanand001.github.io/morph/install.sh | bash

Paste it into a terminal. The installer checks the download against its fingerprint first. A short setup page opens by itself, and no log out is needed. Read the installer.

Try it in your browserSource on GitHub

What it fixes

Tables

Spreadsheet ranges, Slack text tables, psql output and web tables become real tables in Jira, Confluence, email and Docs.

Lists

Odd bullets, a) b) numbering and Outlook's fake lists become proper nested lists.

Code and terminal output

Indentation and line breaks survive, and code lands as a code block.

Right format for each app

Each destination gets what it understands. If a paste already works, Morph leaves it alone and says so.

How you use it

  1. Copy something as usual.
  2. A small pill on the edge of the screen shows what you copied. Click the app you are pasting into.
  3. Paste with Ctrl+V. If it didn't come out right, press Undo to put your original back.

Prefer no clicks? Turn on automatic conversion in setup or Settings, and Morph converts as you switch apps.

Privacy

  • Morph never stores what you copy and never sends it anywhere. Everything happens on your computer.
  • It ignores password managers and copies that apps mark as secret. You can limit it to only the apps you choose.
  • Settings → Privacy shows what Morph read: the time, the app and the size, never the content.
  • The only network use is an optional daily update check and the optional table OCR download.
  • The code is open to read, so you can check all of this yourself.

Optional: tables from images

Morph can read a table from a copied screenshot, on your device, only when you click. It's off by default because it downloads about 1 GB (PaddleOCR). Turn it on in Settings → Privacy → Enable table OCR, or run morph --enable-ocr.

Commands

morph --status      # is it running?
morph --setup       # show the setup page again
morph --restart
morph --update
morph --uninstall   # removes everything: program, helper, settings, logs

Needs GNOME (tested on Ubuntu with Wayland). A .deb for Debian and Ubuntu is also available: morph_0.15.0-rc.1_all.deb.

Found a problem?

Please open an issue with the two apps involved, what you copied and what you got. Include the output of morph --status. For security problems, see the security policy.
