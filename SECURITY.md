# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's **Report a vulnerability** button under this repository's Security tab. Include what you found, how to reproduce it and the version (`morph --status`).

You can expect a reply within a few days. Please give us reasonable time to fix a problem before you share it publicly.

## What Morph touches

Morph reads the clipboard only as described in the README, keeps nothing you copy, and sends nothing over the network apart from the optional update check and the optional image-tables download. Reports that show it doing more than that are especially welcome.
